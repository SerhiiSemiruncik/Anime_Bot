1. Стек
- Мова: Python
- Telegram бібліотека: aiogram
- База даних: SQLite

2. MVP
- Що бот має вміти в першій версії:
  - Пошук аніме за назвою
  - Пошук аніме за жанром
  - Відображення інформації про аніме (кількість епізодів, жанри)
  - Відображення списку епізодів для обраного аніме
  - Відображення списку доступних аніме
  - Надсилання серії користувачеві
  - Можливість обирати епізоди

3. Формат поста в каналі
- Приклад поста:
Назва: Наруто
Серія: 1
#пригоди #комедія

4. Команди бота
- /start: запуск бота та привітання користувача
- /search: пошук аніме за назвою або жанром
- /genres: відображення списку жанрів
- /titles: відображення списку доступних аніме

5. Сутності
- Anime:
  - id
  - Назва
  - Жанри (зв'язок з Genre)

- Episode:
  - ep_id
  - anime_id
  - Номер епізоду
  - telegram_channel_id
  - telegram_message_id

- Genre:
  - id
  - Назва

6. Питання або сумніви
- як підвязати канал до бота, щоб бот міг зчитувати пости з каналу?
